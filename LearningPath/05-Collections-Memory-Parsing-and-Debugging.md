# Section 5 — Collections, Memory, Parsing, and Debugging

## Outcomes

You should be able to:

- choose among arrays, lists, queues, and rolling/ring-buffer models;
- state and test collection invariants;
- parse structured data into useful program state;
- compare shifting data with queue/ring-buffer approaches;
- use deterministic fixtures rather than eyeballing output;
- inspect variables, calls, memory, and registers with a debugger;
- use logs and measurements as debugging evidence.
