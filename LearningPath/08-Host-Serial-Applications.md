# Section 8 — Host Serial Applications

## Outcomes

You should be able to:

- discover and identify serial devices;
- own connection lifecycle explicitly;
- use C# and Python serial APIs;
- distinguish transport from parsing, model, and presentation;
- reason about blocking, buffering, callbacks, and asynchronous receive;
- handle disconnect/reconnect/error state visibly;
- test host logic against fake, captured, or loopback input before live hardware.
