# Section 9 — Persistence and Logging

## Outcomes

You should be able to:

- distinguish text and bytes and choose an appropriate file representation;
- reason about working directory, executable location, project/source location, and explicit paths;
- design timestamped structured records;
- implement append, overwrite, explicit save, naming, rotation, and discovery;
- prove serialize/deserialize round trips;
- replay prior data through the same analysis path;
- handle missing, partial, malformed, and inaccessible files deliberately.
