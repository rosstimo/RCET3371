# Section 10 — Event-Driven Architecture

## Outcomes

You should be able to:

- define explicit application and device states;
- build transition tables before writing callback-heavy code;
- distinguish requested timing from measured timing;
- implement delayed actions and periodic checks without blocking;
- apply hysteresis, interlocks, and fault priority deliberately;
- test time-dependent behavior with controlled or simulated time;
- separate transport, parser, model, control, persistence, and presentation responsibilities.
