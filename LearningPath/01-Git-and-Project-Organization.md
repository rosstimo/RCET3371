# Section 1 — Git and Project Organization

## Outcomes

By the end of this section you should be able to:

- create and inspect a repository intentionally;
- explain working tree, staging area, commit history, local branch, and remote;
- use `status`, `add`, `commit`, `push`, `pull`, `log`, `show`, and `diff`;
- diagnose repository state before attempting recovery;
- organize a programming repository so another person can find, build, and review the work;
- use Git history as engineering evidence rather than as a backup substitute.

## Prerequisites

You should already be able to create, build, and run a small C# program from RCET 2265.

## Practice

**Predict:** Given `git status`, identify which files are untracked, modified, staged, or committed.

**Repair:** Recover from a mistaken edit or commit only after identifying the current state.

**Build:** Create a clean repository for a small program and make a useful sequence of commits.
