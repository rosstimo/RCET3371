# Section 4 — Program Structure and Interfaces

## Outcomes

You should be able to:

- compare loops, functions/methods, and subroutines across the course languages;
- define input/output/state contracts;
- reason about scope, lifetime, storage duration, and retained state;
- use small classes/records as data models;
- use interfaces/module boundaries to separate responsibilities;
- split a program into multiple files deliberately;
- explain CALL/RETURN and the processor stack at an appropriate level.

## Practice

Translate a bounded algorithm across languages without line-by-line imitation. Repair a scope/lifetime defect. Build a two-module solution with an explicit contract.
