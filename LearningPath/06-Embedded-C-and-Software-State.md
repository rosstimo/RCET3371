# Section 6 — Embedded C and Software State

## Outcomes

You should be able to:

- organize embedded C with `.h` interfaces and `.c` implementations;
- explain translation units, external symbols, and linking;
- use fixed-width types and identify when `volatile` is needed;
- separate device/driver responsibilities;
- inspect generated assembly to connect C constructs with processor behavior;
- implement software state machines and polling/callback behavior without blocking;
- compare a small bounded C/assembly interface.
