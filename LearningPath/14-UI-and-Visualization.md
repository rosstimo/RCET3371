# Section 14 — UI and Visualization

## Outcomes

You should be able to:

- choose a presentation layer that fits the engineering problem;
- separate presentation from protocol/domain state;
- reason about coordinate systems, scaling, and transforms;
- maintain rolling-data views;
- preserve display behavior through redraw/resize;
- identify transient drawing and flicker problems;
- expose useful connection, logging, buffer, and fault state.

## Learn

- [UI and visualization](../Topics/ui-and-visualization.md)

## Practice

Predict coordinate transforms. Repair a repaint/state defect. Improve a working system's presentation without moving domain logic into UI callbacks.
