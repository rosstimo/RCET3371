# Section 13 — Linux and Portability

## Outcomes

You should be able to:

- navigate the Linux filesystem and shell;
- reason about users, groups, permissions, processes, packages, environment variables, and PATH;
- use pipes and redirection;
- use SSH appropriately;
- identify serial devices under `/dev`;
- build/run earlier C# or Python work on Linux;
- identify portability assumptions in paths, tooling, and device access.

## Practice
