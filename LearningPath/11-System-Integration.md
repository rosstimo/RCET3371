# Section 11 — System Integration

## Outcomes

You should be able to:

- decompose a device/host system into explicit responsibilities;
- justify language and tool choices;
- document interfaces and protocol boundaries;
- define a verification strategy before live integration;
- progress from fixed data to fake/simulated data, captured data, and then live hardware;
- identify design risks and unknowns;
- explain how a design changed in response to evidence.

## Learn

- [System integration and design readiness](../Topics/11-system-integration-and-design-readiness.md)

## Practice

Review a system architecture and identify hidden coupling. Repair a design that mixes transport, presentation, and control. Build an integration checklist from an interface contract.
