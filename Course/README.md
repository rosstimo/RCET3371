# RCET 3371 Course Guide

RCET 3371 is an advanced comparative programming and software-systems course built on RCET 2265.

The course uses C#/.NET as the familiar high-level reference, Python as a dynamic scripting and engineering-tool language, embedded C/XC8 as the hardware-facing compiled language, and PIC assembly/`pic-as` to expose processor-near behavior.

## How the course is organized

Use the [Learning Path](../LearningPath/) as the ordered route through the course.

Durable material lives by purpose:

- [Topics](../Topics/) teach concepts.
- [Guides](../Guides/) teach recurring workflows and tool use.
- [References](../References/) provide quick lookup.
- [Standards](../Standards/) define course requirements.
- [Programming Assignments](../ProgrammingAssignments/) define graded programming work.
- [Examples](../Examples/) provide runnable or traceable demonstrations.
- [Resources](../Resources/) provide supporting data and starter assets.

Sections are not calendar weeks. An instructor may cover multiple sections in one week or spend multiple weeks on one section.

## Grading model

The Spring 2027 course design uses two grade categories:

- **Programming Assignments: 50%**
- **Quizzes and Assessments: 50%**

Programming Assignments include bounded practicals, larger multi-section projects, and the final integration/verification portfolio.

Quizzes and Assessments may be delivered in Canvas or on paper.

## Learning approach

Across the course, practice repeatedly uses four modes:

- **Predict** — determine output, state, or behavior before execution.
- **Translate** — express the same behavior in another language or representation.
- **Repair** — diagnose, explain, fix, and verify a failure.
- **Build** — implement from requirements and test cases.

The goal is to understand not only syntax, but also how the engineering problem, algorithm/state model, language, runtime, operating system, and hardware interact.
