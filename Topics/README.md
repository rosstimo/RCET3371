# RCET 3371 Topics

This directory contains durable concept-centered learning material.

Use the [Learning Path](../LearningPath/) when progressing through the course in order. Use this index when reviewing or remediating a specific concept.

The complete topic corpus covers:

1. Git and project organization
2. toolchains and recovery
3. values, representation, and decisions
4. program structure and interfaces
5. collections, memory, parsing, and debugging
6. modular embedded C and software state/events
7. serial communication and protocol design
8. host serial applications
9. persistence, logging, configuration, and error handling
10. event-driven device/host architecture
11. system integration and design readiness
12. collaborative development
13. Linux systems and portability
14. UI and visualization
15. advanced software-system techniques
16. integration, verification, and design review

Topic documents are written so students can learn or review them independently and include worked examples, practice, answer reasoning, and authoritative references where appropriate.
