Follow the [Learning Path](../LearningPath/) for required sequence rather than inferring requirements from example names.

## Example standard

A teaching example should:

1. state what prior idea it starts from;
2. show the complete runnable/traceable example;
3. state how to build/run it;
4. show expected behavior;
5. explain the new idea in small steps;
6. provide at least one safe modification to try;
7. state platform/toolchain assumptions.

Examples are demonstrations, not answer keys for graded Programming Assignments.
