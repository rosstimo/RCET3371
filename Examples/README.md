# RCET 3371 Examples

Runnable and traceable examples used throughout RCET 3371.

## S27 core examples

- [Status Decoder](StatusDecoder/) — packed fields and fixed-width behavior in C# and Python
- [Protocol Parser](ProtocolParser/) — streaming framing/check validation in C#
- [Controlled-Time State Machine](StateMachine/) — deterministic state/timing behavior in C#
- [File Round Trip](FileRoundTrip/) — structured CSV persistence/replay concept in Python

## Existing examples retained for reference

Earlier examples covering engineering notation, file I/O, graphics/WinForms, key events, Linux serial, OOP, serial ports, and Qy@ host/device work remain useful reference material while the S27 course is completed.

Follow the [Learning Path](../LearningPath/) for required sequence rather than inferring requirements from legacy example names.

## Example standard

A nontrivial example should state what it demonstrates, how to run/inspect it, expected behavior, and platform/toolchain assumptions.

Examples are demonstrations, not answer keys for graded Programming Assignments.
