# Programming Assignment — Integration/Verification Portfolio

[Programming Assignments index](../README.md)

**Points: 200**  
**Sections: 12–16**

## Objective

Produce bounded evidence demonstrating collaborative engineering workflow, Linux portability, presentation/visualization, one advanced extension, and final reproducibility/design verification.

This is **not** the program capstone.

## Portfolio structure

```text
portfolio/
├── collaboration/
├── linux/
├── visualization/
├── advanced/
└── final-verification/
```

Evidence may reference earlier course repositories rather than copying entire projects.

## Required components

1. **Collaborative Git:** issue/need, focused branch, meaningful commits, pull request, review, conflict/integration evidence where applicable, cleanup, and one integration decision.
2. **Linux portability:** clean clone of an earlier C#/Python program on Linux, documented setup, build/run, deterministic input/output, and portability fixes.
3. **UI/visualization:** retained-state presentation, repaint/resize behavior, coordinate/data mapping, meaningful system state.
4. **Advanced extension:** one approved bounded path: testing/regression, async/concurrency, networking/HTTP/JSON, packaging/CI, or compiler/disassembly/performance.
5. **Final verification:** clean-clone instructions, requirement/evidence matrix, normal/boundary/failure evidence, selected Git-history evolution, architecture explanation, limitations/unverified assumptions.
