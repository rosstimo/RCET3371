# Integration and Verification Portfolio Rubric

Total: **200 points**

| Area | Points |
| --- | ---: |
| Collaborative Git contribution/integration evidence | 30 |
| Linux portability verification | 30 |
| UI/visualization architecture and behavior | 35 |
| Advanced extension and evidence | 35 |
| Final verification matrix / failure evidence | 45 |
| Design review / handoff quality | 25 |

## Full-credit standard

The portfolio must be reproducible from repositories and documentation. Evidence that exists only as screenshots without a traceable commit, test, input, or requirement is insufficient.
