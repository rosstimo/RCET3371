# Cross-Language Engineering Model Milestones

Milestones are progress/checkoff points. The final grade is based on the completed Programming Assignment and rubric.

## Milestone 1 — Contract and vectors

- repository created;
- specification read;
- vector file copied/referenced without changing expected values;
- C# data model/API skeleton;
- tests load or encode all vectors.

## Milestone 2 — C# and Python equivalence

- C# implementation passes vectors;
- Python implementation passes vectors;
- fixed-width differences documented;
- comparison output generated.

## Milestone 3 — XC8 module

- `.h/.c` interface complete;
- clean PIC16F883 build;
- logical vectors verified through simulator/test harness or documented host-side equivalent;
- generated assembly captured for one bounded function.

## Milestone 4 — pic-as routine and final evidence

- selected routine implemented;
- subroutine contract documented;
- applicable vectors verified;
- cross-language comparison complete;
- clean-clone instructions verified.
